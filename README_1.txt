BARGAIN FINDER UK VERSION 3

New: comparison offers are grouped by exact product name and condition, so New and Used listings are not mixed. The lowest total price within each group is highlighted. Optional key specifications are shown for manual like-for-like checking. Existing v2 local data is migrated on first load.

To update GitHub Pages: replace index.html, styles.css, app.js, manifest.json and sw.js in the repository and commit. Reopen the website/app. The service worker cache version has changed to refresh the app files.

This app does not automatically fetch retailer prices. Users enter prices and delivery manually. No paid services or API keys are used.
