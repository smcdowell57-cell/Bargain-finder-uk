BARGAIN FINDER UK — FREE FIRST VERSION

WHAT THIS VERSION DOES
- Runs as a mobile-friendly website.
- Provides search links for Amazon UK, eBay UK, Google Shopping, Argos, Tesco and OnBuy.
- Lets you save products, record prices, set target prices and view the prices you have recorded.
- Stores your list in this browser on this device.
- Can be installed as a PWA after it is published over HTTPS.

IMPORTANT LIMITATIONS
- Retailer links open each retailer's own search results. This version does not automatically scrape retailer pages or fetch live prices.
- Price tracking is manual: enter a new price when you find one.
- Data is stored in the browser on this device. Clearing browser data may remove it.
- It does not send background push notifications.
- Do not treat a search result as a verified deal; check delivery, seller, condition, specification and checkout total.

PUBLISHING FOR FREE
1. Create a GitHub account if you do not already have one.
2. Create a new public repository named bargain-finder-uk.
3. Upload all files in this folder to the repository root (not inside another folder).
4. In repository Settings > Pages, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Wait for GitHub Pages to publish the site. Open the Pages URL on your Android phone.
7. In Chrome, use the three-dot menu > Add to Home screen or Install app if offered.

No paid service or API key is used by this first version.
