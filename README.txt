BARGAIN FINDER UK VERSION 2

New: compare offers for the same product, include delivery charges, sort by total price or rating, and save optional product links.

To update: in your GitHub repository replace index.html, styles.css, app.js, manifest.json and sw.js with these files, then commit changes. Reopen your Pages website. If the installed app still shows the old version, fully close and reopen it.

This is a manual comparison tool. It opens retailer search pages but does not automatically scrape or fetch live retailer prices. Prices and delivery are entered by the user. Data is stored in this browser on this device. No paid services or API keys are used.
